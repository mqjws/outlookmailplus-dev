# 验证码能复制，但邮件列表看不到

验证码按钮会检查收件箱和垃圾邮件；邮件列表只展示当前选中的文件夹。若验证邮件被 Outlook 放入垃圾邮件，验证码仍能提取，但收件箱列表不会出现它。这不是邮件丢失，也不是验证码接口绕过了邮件读取。

## 查看邮件

- 选择账号后，界面优先打开账号摘要里最新邮件所在的文件夹，没有摘要时打开收件箱。
- 点击“垃圾邮件”或“收件箱”会自动加载对应文件夹；“获取邮件”刷新当前文件夹。
- 在已选账号的卡片上点击验证码，成功后会刷新验证码来源文件夹；垃圾邮件验证码的复制提示会标明来源。
- 在邮件详情里提取验证码时，不会自动切换文件夹，避免打断正在查看的邮件。
- 修改前端文件后，用 Ctrl+F5 强制刷新浏览器。不需要重启后端或重新导入账号。

## 判断原因

管理界面的 `/api/emails/<邮箱>?folder=inbox` 和 `?folder=junkemail` 分别读取收件箱与垃圾邮件。验证码提取日志的 `channel=graph_junk` 表示成功从垃圾邮件读取，账号摘要的 `latest_email_folder=junkemail` 也能确认文件夹。

如果希望后续邮件进入收件箱，请在 Outlook 官方邮箱中将相应邮件标记为“非垃圾邮件”，并按需要添加安全发件人。管理器不会擅自移动邮件或修改 Outlook 的反垃圾邮件设置。
